# PaperLens 0.1.0 测试版（2026-09-22）

## 本次更新

- 修复系统 WebKit 缺少 ReadableStream 异步迭代接口导致 PDF 阅读失败的问题。
- 将文字层失败与页面绘制失败分开，文字提取失败不遮挡已经画好的页面。
- 概念解释从 OpenAlex 学术主题改为通用释义：少量内置词条 + 通用百科；英文词条优先读取对应中文词条，再尝试机器翻译。
- 标注来源和其他含义，不将百科搜索匹配当作论文中的确定定义。网络不可达时明确提示，不凭空编造解释。

## 已验证的范围

- 174 项自动化测试通过。
- 系统 WKWebView：MetaFormer 和 RAGAs 的页面、文本选择、翻页和缩放。
- 系统 WKWebView + 生产压缩代码：苹果、NVIDIA V100 GPU、自行车、photosynthesis 的真实释义查询通过。
- 以上不是整个应用、全部 PDF 或全部 macOS 版本的完整验收。

## 安装与兼容性

- 本次提供 ARM64 构建，仅用于 Apple Silicon（M 系列）Mac，不适用于 Intel Mac、Windows 或手机。
- 打开 DMG，将 PaperLens 拖到“应用程序”。更新前退出旧版；不需要安装 Node.js、Rust 或开发工具。
- 当前实际验证系统为 macOS 26.6.2；尚未做旧版系统或另一台物理 Mac 的兼容验收。
- 未配置 Developer ID 签名证书和 Apple 公证。首次运行可能被 Gatekeeper 阻止。确认文件来自可信渠道后，可按 Apple 官方说明在“系统设置 → 隐私与安全性”中允许此应用；不要关闭系统整体安全保护。
- 官方说明：https://support.apple.com/en-gb/102445
- 阅读本地 PDF 不要求联网；搜索、下载、百科和翻译依赖对应网络服务。
- 安装包不包含当前电脑的个人 PDF、资料库、学校登录状态或账号信息；资料不会自动同步到其他电脑。
