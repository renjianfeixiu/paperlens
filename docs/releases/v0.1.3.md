PaperLens v0.1.3：PDF 优先、本地优先的科研阅读 MVP。

## 下载与安装

- Mac Apple Silicon（M1 / M2 / M3 / M4 等）：`PaperLens-0.1.3-macOS-AppleSilicon.dmg`。
- Mac Intel：`PaperLens-0.1.3-macOS-Intel.dmg`。
- Windows 10 / 11 x64：`PaperLens-0.1.3-Windows-x64-setup.exe`。
- `SHA256SUMS.txt` 和 `release-manifest.json` 提供文件校验与源码版本信息。

普通使用无需 Node、pnpm、Rust 或 Codex。Mac 将应用拖入 Applications；Windows 默认为当前用户安装，缺少 WebView2 时联网安装运行环境。

## 功能

论文聚合搜索、合法开放全文获取、本地 PDF 导入与阅读、页码 / 缩放 / 划词、进度恢复、选区翻译、公式结构提示、概念查询和引用线索。沿用 0.1.3 的原始论文入口与阅读 / 下载错误信息修复。

当前翻译使用 MyMemory，概念解释使用内置词条与维基百科，没有声称已接入真实多模态大模型。选区翻译和概念查询按用户点击发送必要文本；基础阅读不会自动上传全文。

## 验证与边界

三个平台均已完成原生构建：每个平台 232 项前端测试、13 项常规 Rust 测试通过（另有 1 项联网测试 ignored）；生产构建、架构 / 版本及安装包检查通过。[构建记录](https://github.com/renjianfeixiu/paperlens/actions/runs/37970818704)。

三个实际安装包的文件长度与 SHA-256 已复核，两个 DMG 已在本机只读挂载并核对包内应用。全部安装包对应源码提交 `16214b2a2c22bfb0a07d932fadf5fd742247eb3b`。完整结果见 [平台验证记录](https://github.com/renjianfeixiu/paperlens/blob/main/docs/RELEASE_VERIFICATION.md)。

这是测试版。Mac 使用 ad-hoc 签名，没有 Apple Developer ID 签名和公证；Windows 未做发布者代码签名。Intel / Windows 的完整 GUI 与升级卸载验收单独记录，构建成功不代表已完成所有实机验收。外部索引和下载渠道仍可能限流或不可用。
