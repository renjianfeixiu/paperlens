# PaperLens 0.1.0 · Intel Mac 测试版

打开 DMG，将 PaperLens 拖入“应用程序”。更新前请退出旧版本。

本安装包包含 x86_64 程序，只适用于 Intel Mac。它在 Apple Silicon 主机上交叉编译，已验证程序架构、安装包完整性及签名，但尚未在一台 Intel Mac 上运行验收。旧版 macOS 的兼容性也尚未逐一验证。

本版本未经 Apple Developer ID 签名和公证。确认文件来源可信后，如果 macOS 拦截首次启动，请依照 [Apple 官方说明](https://support.apple.com/en-gb/102445)在“系统设置 → 隐私与安全性”中允许打开。不要关闭整个系统的安全保护。

本地 PDF 阅读无需联网；论文搜索、获取全文、百科释义与翻译需要访问相应网络服务。安装包不含个人 PDF、资料库、登录信息，也不会自动从另一台 Mac 同步数据。
