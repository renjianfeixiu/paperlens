# PaperLens 分阶段实施计划

为了便于控制开发额度，每个阶段完成、验证并汇报后暂停；只有收到“进行下一阶段”后才继续。

更新：用户随后允许持续改进。以下阶段仍用来记录范围，不把代码完成等同于线上下载成功率达标。

## 2026-09-22 稳定性补强

- 打开推荐、期刊文章和关联论文时，清除不兼容筛选并使旧搜索失效；关联论文不会再被原结果列表挤掉。
- 新期刊搜索使旧文章请求失效，防止旧结果覆盖新期刊；推荐刷新也遵循最后一次请求优先。
- 改变 PDF 选区后，旧翻译和概念解释不再显示在新选区上。
- 每个全文补查渠道最多等待 12 秒，保留其他渠道的成功结果并显示失败提示；查询失败不代表没有全文。
- 加入界面乱序返回回归测试和全文渠道挂起测试。学校认证及浏览器下载导入仍需真实账号场景验收，不能据此宣称多数论文都能直接下载。

## 第一阶段：基础可运行版收口

状态：已完成。

- 保留单一 PaperLens 开发副本，旧安装移入废纸篓并取消应用注册。
- 打通 OpenAlex + Crossref 真实论文检索、去重、来源标记与本地筛选。
- 打通 macOS 原生 PDF 选择、私有目录复制、重启恢复和文件名安全处理。
- 支持 PDF 分页、缩放、页码跳转和阅读进度恢复。
- 提供 OpenAlex 参考文献、被引论文与相关推荐的数据层及发现页入口。
- 完成单元测试、TypeScript 构建和 macOS 调试版打包验证。

## 第二阶段：合法全文下载与阅读闭环

状态：已完成。

- 用结构化全文位置区分 PDF 直链与来源落地页，并保留版本、许可和宿主信息。
- 仅对索引明确标记为开放获取的 HTTPS PDF 提供“下载并阅读”。
- 下载由 macOS 原生层完成，含重定向逐跳检查、私网地址阻断、超时、100 MiB 上限、PDF 签名校验和原子写入。
- PDF 保存到 PaperLens 的 AppLocalData 私有目录，并绑定原论文元数据、DOI、作者和阅读进度。
- 已下载论文可在资料库跨重启恢复；重复点击不会并发下载同一论文。
- 登录、付费、验证码、非 PDF 响应或仅有落地页时，明确提示并交给系统浏览器，不绕过来源网站权限。

## 第三阶段：原文理解闭环

状态：已完成。

- PDF 文本层、真实划词与页码锚点。
- 右侧栏接收真实选区，而不是固定示例。
- 英中逐句翻译接口、公式保护、失败与隐私提示。
- 概念和公式解释的可展开结构及证据定位。

## 第四阶段：引用与全文来源完善

状态：全文来源增强已完成；基础 PDF 引用线索已可用，精准书目解析和缓存待后续。

- 正文引用识别、引用卡和引用上下文。
- 完善引用/被引/相似论文浏览、缓存与错误降级。
- 已并行接入 CORE 和 Europe PMC，并保留发行版可选 Unpaywall 补查；用户无需填写 Unpaywall 邮箱。
- 已补充可信学术落地页 PDF 元数据解析、多个开放 PDF 候选及失败自动切换。
- 已接入学校代理/图书馆入口和浏览器下载后自动导入，不读取账号、Cookie，不绕过付费墙、验证码或 DRM。
- 已显示多个开放 PDF 候选来源并允许指定优先下载；浏览器新 PDF 会先核对文件名再关联。
- 已从当前 PDF 页面识别数字式/作者年份式引用标记与原文上下文，尝试映射文末编号书目；不推测引用意图。

## 第五阶段：资料库、笔记与发布

状态：发现系统已加入真实近期论文推荐和期刊浏览基础版；笔记与发布尚未完成。

- SQLite + FTS5 资料库、迁移、备份和孤儿文件清理。
- 高亮、笔记、全文搜索与导出。
- 已有 OpenAlex 实时近期论文推荐、期刊名称/ISSN 搜索与期刊论文分页；会议浏览、卷期、关注和更稳定的个性化推荐待做。
- 性能基准、复杂 PDF 测试集、签名、notarization 和正式 DMG。
