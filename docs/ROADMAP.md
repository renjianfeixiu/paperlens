# PaperLens 迭代路线

## 当前阶段：可连续阅读的 MVP

保留检索、合法全文获取、本地 PDF 阅读、文本选择和进度恢复闭环；Mac 和 Windows 构建来自同一源码版本，功能完成与平台实测分开记录。

## 下一阶段：阅读可靠性

- 完成 Windows WebView2、安装升级、中文路径和重启恢复的真实环境验收。
- 建立公开 PDF 排版样本集，覆盖多栏、公式、作者年份引用和扫描版边界。
- 补充网络失败和离线状态恢复；控制外部渠道故障对阅读的影响。
- 配置正式发布者签名和 macOS 公证。

## 后续阶段：有证据的阅读辅助

- 按用户确认接入模型服务，明确选区发送范围、凭据存储、费用与取消。
- 将回答绑定原文页码、段落、公式和引用，区分原文事实、推导和背景。
- 使用可核对的样本评估翻译与解释，不以演示内容代替质量指标。

## 数据与扩展

逐步实现笔记、批注导出、SQLite / 全文索引和本地备份。OCR、EPUB 和其他格式根据真实需求推进；首版保持 PDF 优先。
