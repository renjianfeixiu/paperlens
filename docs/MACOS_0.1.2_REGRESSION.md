## 先复现，再修复

新增测试先观察到失败，再修改实现：

| 操作 | 修复前结果 | 0.1.2 处理 |
| --- | --- | --- |
| 第一页输入 `0`，或末页输入 `999` | 实际页码已限幅，输入栏却保留错误数字 | 输入框与实际显示页同步 |
| 输入另一页后按 Esc | 失焦事件把本应取消的页码提交 | 取消时跳过失焦提交 |
| 滚到页底后翻页 | 新页面仍停在底部 | 页码 / 文档变化时回到页首；缩放不主动重置滚动位置 |
| 导入 `论文 draft..v2.pdf` 后重新加载 | 将文件名里的连续点误判为目录穿越 | 允许文件名内的点，仍阻止额外目录、反斜杠和控制字符 |
| 导入长中文文件名或截断位置含 emoji | 可能超过文件名字节限制，或切断 Unicode 字符 | 完整字符截断，名称主体最多 180 个 UTF-8 字节，并保留前缀空间 |

另外补充了目录穿越与空字符的拒绝用例。文件名缩短只作用于资料库内的保存路径，导入时的原始显示名称保留。
